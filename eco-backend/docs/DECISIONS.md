## Private preview on Render (ENV=preview), 2026-11-21 — awaiting approval of spend
- New `ENV=preview`: counts as deployed (https, JSON logs, API docs hidden, AI daily budget + model prices required)
  but allows `UPLOADS_ENABLED=false` (then local storage and no scanner are accepted), `EMAIL_BACKEND=none`, and
  requires `SIGNUP_ALLOWLIST`. staging and prod keep every guard (tested).
- `render/preview.yaml` (FREE plan, chosen by Stephen 2026-11-21): Postgres 16 free (expires after 30 days, no backups),
  the API as a public free web service (free services cannot receive private traffic), the web service; both sleep
  when idle. Paid alternative kept in the file header (private API, basic-256mb). Originally: the web as the
  only public service. Render builds from the Dockerfiles in this repo.
- Database roles: Render's default user (not a superuser) is the owner and runs migrations; `scripts/render_start.py`
  creates the restricted `eco_app` role (checked: no superuser/BYPASSRLS/CREATEROLE) and starts the API as eco_app.
- No backups beyond what Render's plan provides; no uploads, so no file storage to back up.
- Blank secret fields (e.g. OPENAI_API_KEY left empty in the dashboard) mean "not configured".

## Open sign-up on the preview (Stephen, 2026-11-23)
- `SIGNUP_OPEN=true` lets anyone sign up (overrides `SIGNUP_ALLOWLIST`); preview requires one of the two, on purpose.
- Free plan: the web server reaches the API over the internet, so every visitor looked like the web server's IP and
  per-IP sign-up/sign-in limits would have been shared by everyone. The web server now also sends the visitor chain
  it received plus `WEB_FORWARD_SECRET` (generated by Render, shared by both services); the API believes that chain
  only with the right secret (constant-time compare). Tested: right/wrong/missing secret, feature off.
- Accepted risks for an open preview: AI spend is on Stephen's key (capped $5/day overall, $10/month per user); the
  privacy policy and terms are still drafts with placeholders; the free database expires 30 days after creation.
